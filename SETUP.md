# Запуск Recordly Lite

Редактор видео без записи экрана: импорт готового файла, ручные зумы,
стилизация кадра и экспорт. Разрешения на запись экрана, камеру и микрофон
приложение не запрашивает — захват вырезан из кода.

---

## Что нужно заранее

| Компонент | Версия | Проверить |
|---|---|---|
| Node.js | 20+ (проверено на 25.6) | `node -v` |
| npm | 10+ | `npm -v` |
| macOS | 14.0+ | `sw_vers` |
| Xcode Command Line Tools | любая | `xcode-select -p` |

Если Command Line Tools не стоят:

```bash
xcode-select --install
```

Windows и Linux должны работать, но проверялось только на macOS (Apple Silicon).

---

## Установка

```bash
git clone https://github.com/TuxooTurr/recordly-lite.git
cd recordly-lite
npm install
```

Установка занимает около 30 секунд. Долгой сборки нативных помощников, как в
оригинальном Recordly, здесь нет — они удалены вместе с записью экрана.

---

## Запуск

```bash
npm run dev
```

Приложение открывается **сразу в редакторе** — окна записи не существует.
Первый запуск дольше остальных: Electron докачивает свой бинарник (~100 МБ).

### Быстрый запуск одной командой

Добавь в `~/.zshrc`:

```bash
recordly-lite() {
  cd "$HOME/Documents/MyProject/Recordly_Lite" || return 1
  [ -d node_modules ] || npm install || return 1
  npm run dev
}
```

После `source ~/.zshrc` достаточно набрать `recordly-lite` из любого места.

---

## Как пользоваться

1. **Импорт.** `Home` → `Import` → выбери файл (mp4, mov, webm, avi, mkv).
2. **Зумы.** Поставь курсор на нужный момент таймлайна и нажми **`Z`** или
   кнопку `Add Zoom`. Зум растягивается и двигается мышью, масштаб и точка
   фокуса настраиваются в панели справа.
3. **Фон и рамка.** Вкладка `Scene`: обои, градиент или цвет, размытие,
   скругление углов, тень и отступы вокруг кадра.
4. **Экспорт.** Кнопка `Export` справа вверху — MP4 или GIF.

Проект сохраняется в файл `.recordly` и открывается позже с сохранённым
состоянием.

## Если что-то не так

**Порт 5173 занят.** Vite сам возьмёт следующий свободный — посмотри в выводе
строку `Local:`. Освободить принудительно:

```bash
lsof -ti:5173 | xargs kill -9
```

**Окно не появилось, в логе `ERR_CONNECTION_REFUSED`.** Vite-сервер не
поднялся. Останови всё и запусти заново:

```bash
pkill -f "Recordly_Lite/node_modules/electron/dist"; pkill -f "Recordly_Lite/node_modules/.bin/vite"
npm run dev
```

**`SetApplicationIsDaemon: Error ... (-50)` в логе.** Безвредный шум Electron
на macOS, есть и в оригинальном Recordly. Игнорируй.

**Сборка собранного приложения не открывается: «Приложение повреждено».**
Локально собранные сборки macOS помещает в карантин:

```bash
xattr -rd com.apple.quarantine /Applications/Recordly\ Lite.app
```

**Нужно вернуться к чистому состоянию.**

```bash
rm -rf node_modules dist dist-electron
npm install
```

## Параллельная работа с обычным Recordly

Обе версии можно держать запущенными одновременно — они разведены:

| | Recordly | Recordly Lite |
|---|---|---|
| данные | `~/Library/Application Support/Recordly-dev` | `~/Library/Application Support/Recordly-Lite-dev` |
| порт Vite | 5173 | следующий свободный (обычно 5174) |
| порт OAuth | 43821 | 43822 |

Из-за разных папок данных **проекты между версиями не видны друг другу**.
Готовые видеофайлы это не затрагивает — их можно импортировать в обе.

## Вход в приложение

В режиме разработки работает демо-аккаунт без всякой настройки:

```
test@email.com / 1234
```

Облачные функции (шаринг) при этом недоступны — для них нужен Supabase,
ключи задаются в `.env` по образцу `.env.example`. Для импорта, зумов и
экспорта ничего этого не требуется.
