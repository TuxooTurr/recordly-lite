Запусти Recordly локально в режиме разработки.

Шаги:
1. Убедись, что ты в `/Users/stefanzastylov/Documents/MyProject/Recordly`.
2. Если `node_modules` отсутствует — выполни `npm install` (первый запуск долгий: собираются нативные хелперы).
3. Запусти `npm run dev` в фоне, логи пиши в `/tmp/recordly-dev.log`.
4. Дождись строки `ready in` / `VITE` в логах и сообщи адрес dev-сервера.
5. Кратко отчитайся: поднялось ли окно Electron, есть ли ошибки в логе.

Важно:
- Demo-логин в dev-сборке: `test@email.com` / `1234` (Supabase не требуется).
- Ошибки прав на запись экрана/микрофон решаются в Системных настройках → Конфиденциальность.
- Не запускай `npm run build` без отдельной просьбы — это полная упаковка приложения.
